# The Sigil, phase 1: the program, the line, the Pill and islands, wave 1 — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a running `mooi-sigil` program that draws the Sigil (one living 64-point line) in the Pill and in any island that hosts it, showing the wave-1 sources at glyph, compact and display size, chosen by a director and coloured by the palette — beside the classic Pill, switched by `sigil.pill`.

**Architecture:** five pure Luau modules under `shell/lib/sigil/` decide everything (sources, shapes, director, palette, bodies, plus `hosts` for the bar's side); `shell/mooi-sigil.luau` wires them to files, services and facts; `shell/mooi-sigil.plm` is generated by `tools/gen-sigil.py` (64 sprung points per host, the line, the field, the displays' insides). The bar publishes `sigil-hosts.json` and `sigil-feed.json`; mooi spawns the program like the frame.

**Tech Stack:** Pleamar 0.7.11 (language 0.9) scenes, Luau logic (Lua 5.4 for unit tests), Python 3 generators, POSIX sh live tests.

**Spec:** `docs/superpowers/specs/2026-11-07-sigil-design.md`

**Phasing (decided here, not in the spec):** this plan builds glyph, compact and display. A press **opens the module's existing panel** (`open = calendar · weather · music · sound · stats · power · system · overview`, the board, the Nexus) until the detail views are built from the parts vocabulary in a later plan. Later plans: the pointer host; Venom and Circuit; context (focus, hover preview, icon silhouettes, fullscreen); detail views; wave 2; retiring the classic Pill.

## Global Constraints

- Draw only on the program's own surfaces; never touch `shell/mooi-frame.plm` or the frame's band (spec §2).
- Never watch `notifications` or `notification_history` outside `signals.luau`; notices come from `nexus-feed.json` (spec §3).
- Setter codes append-only: `lib/setters.luau` and `tools/gen-settings.py` lists end with the new paths, nothing moved.
- Never hand-edit generated blocks: `<gen:...>` in `mooi-settings.plm`, all of `mooi-sigil.plm` below its header.
- Requires use slashes (`require("lib/sigil/shapes")`); the gate refuses dotted names.
- `N = 64` points per host; at most 4 hosts in this phase (host 0 the Pill, hosts 1–3 islands).
- Each host surface under 1 ms compose + paint at 60 fps; `rate: 60, 20 while calm`; nothing redrawn while still (spec §11).
- Reduced motion (`settings.motion.reduced` or `saver == "always"`): every change at once, no wobble, no breathing.
- Default `sigil.pill = "classic"`: the owner's bar does not change until they switch.
- Live tests restore `settings.json` byte for byte, the players and volume; never move the real pointer; `trap` EXIT, INT, TERM and PIPE.

## Review Focus

1. **No hosts file, or one with zero hosts** (classic mode, no `sigil` module): the program runs, draws nothing, maps no surface, costs ~0 — pinned in Task 9's `tests/sigil.sh` (surfaces unmapped) and Task 6's `hosts.build` test (empty list).
2. **Two islands host the sigil and only one thing is happening**: they never show the same source; the second falls back to its resting source — Task 5 test `director: two hosts never share a source`.
3. **A feed that stops updating** (the bar killed, `sigil-feed.json` an hour old): its sources show a dash in compact and the director skips them — Task 5 test `director: stale feed sources are skipped`, Task 3 test `sources: compact of a missing reading is a dash`.
4. **A host box narrower than its form needs** (an island given 60 px): shapes clamp into the box, never outside it, and the compact text is cut, not overflowing — Task 2 test `shapes: every kind stays inside a 60 x 24 box`.
5. **The program crashing in a loop**: five quick deaths, then the bar draws its plain clock in the Pill box and logs once — Task 7 test `mooi: sigil respawn gives up after five and the bar falls back`.

### Task 5: `lib/sigil/director` — what each host shows

**Files:**
- Create: `shell/lib/sigil/director.luau`
- Test: `tests/unit/run.lua` (section `the sigil: director`)

**Interfaces:**
- Consumes: `sources.get`, `sources.WAVE1`.
- Produces: `M.choose(hosts: { {id, kind, rest: source id} }, state: State, now: ms) -> { [host id] = { source: id, form: "glyph"|"compact"|"display", event: string|nil } }`.
- `State = { music = { playing, title }, notice = { at, app, title }|nil, battery = { percent, charging }, volume_at = ms|nil, feed_at = ms, open = { [host id] = true }, hover = { [host id] = true } }`.
- Rules, in order: (1) a notice younger than 6000 ms → `notifications` (event `notable`); (2) battery ≤ 15 and not charging → `battery` (event `warning`); (3) a volume change younger than 2000 ms → `volume`; (4) music playing → `music`; (5) the host's `rest`. Each rule's source goes to the **first host (Pill first, then islands in order) not yet given one**; a host never repeats a source another host already shows; a host left over shows its `rest` unless taken, else the next free wave-1 source in `WAVE1` order. Form: `display` when the host kind is `pill` and (`hover[id]` or `open[id]`); else `compact`; `glyph` when the host's box height is under 18. Sources read from the feed (`weather`, `resources`) are skipped when `now - state.feed_at > 30000`.
