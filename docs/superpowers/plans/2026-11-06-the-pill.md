# The Pill — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shape → Pill: a capsule at the top centre showing the most important thing happening, with moons (satellites) or a split for the next ones, alone or with the side groups, hanging from the frame when it is on.

**Architecture:** A pure `lib/pill` decides main, moons, split and width from the activities; the bar's logic feeds it from the services it already watches, lays out the side groups as islands with an empty centre, places the Pill and moons in the middle, and writes their places into `bar-geo.json`; `lib/chassis` turns them into pieces (joined to the band when the frame is on); `shell/ui/pill.plm` draws the content.

**Tech Stack:** Pleamar 0.7.11 scenes + Lua logic, Python generators, POSIX sh live tests, Lua 5.4 unit tests.

**Spec:** `docs/superpowers/specs/2026-11-06-the-pill-design.md` (D168)

## Global Constraints

- Requires with slash paths; no `goto`; `show:` is ignored on shapes inside a `body`; a box with `stroke: 0` is filled; events from outside a scene must be declared.
- `settings.json` only through `lib/settingsfile`; setter codes append-only; generated files change only through their generators (`gen-settings` also owns the bar's `<gen:edit>` block).
- One bottom edge (the Pill's foot is the bar's foot); one outline width; swell moves the band and what hangs from it.
- After logic changes: `bin/mooi session`, no new `runtime error` in `~/.local/state/mooi/mooi.log`.
- Live tests restore `settings.json` byte for byte, the volume and the playback state; never move the pointer.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `setup/capture.sh` before a pushed commit.

## Review Focus

1. Nothing active but idle, then music starts and a notification arrives in the same second: main is the notification (higher in the default order), music is a moon; after 6 s music is main again and no moon is left.
2. Every activity switched off in `pill.off`: idle still shows (it cannot be switched off).
3. A volume change while the Pill shows music: with satellites, osd is a moon for 2 s; with split, the Pill shows music | VOL side by side.
4. Pill mode with `pill.sides = hide`: no side islands are drawn and no module of the centre group is drawn as a module.
5. Switching Shape from Pill back to Islands: the centre group's modules come back exactly where they were (the settings lists were never changed).

### Task 1: Schema and `lib/pill`

**Files:** Modify `shell/lib/config.luau`; Create `shell/lib/pill.luau`; Test `tests/unit/run.lua` (section "pill")

**Interfaces:**
- Produces: `config` keys of spec §2 (`pill.off`, `pill.order` as `ids` lists, validated against `pill.ACTIVITIES`).
- `pill.ACTIVITIES = { "battery", "record", "notify", "music", "osd", "idle" }`; `pill.OSD_MS = 2000`,
  `pill.NOTIFY_MS = 6000`, `pill.CHARGE_MS = 4000`, `pill.PIN_MS = 6000`, `pill.LOW = 15`.
- `pill.state()` → a fresh activity state `{ media = {}, battery = {}, recording = false, rec_since = 0, osd = nil, notify = nil, charge_at = nil, pin = nil }`.
- `pill.note(st, kind, payload, now_ms)` records an event: `"media"` `{playing, title, artist}`,
  `"battery"` `{percent, charging}` (sets `charge_at` on a false→true charging edge), `"recording"`
  `{on}`, `"osd"` `{kind = "vol"|"bri", value = 0..1}`, `"notify"` `{app, summary}`, `"pin"` `{id}`.
- `pill.compute(st, cfg, now_ms)` → `{ main = id, moons = { id… }, split = bool, two_lines = bool, width = number, view = { [id] = { glyph, t1, t2, value } } }`
  with `cfg = { order = {…}, off = { [id] = true }, moons = n, multi = "satellites"|"split" }`;
  active rules per spec §3; a pinned id (≤ PIN_MS old) is main; `idle` is always active and never a moon;
  split → the first moon becomes the split partner and `moons` loses it; width:
  `max(120, 24 + 7 * #t1 + (t2 and 0 or 0))` for one view, the sum + 8 for split; `two_lines` when main is `notify`.
- `pill.next_change(st, now_ms)` → ms until a timed activity expires (or nil), for the logic's timer.

  wins for 6 s; `moons` capped at `cfg.moons`; config defaults and an unknown activity id in `pill.order`
  refused with a problem.
- [ ] **Step 2: Run** `lua5.4 tests/unit/run.lua --filter pill` — Expected: FAIL (module missing)

**Files:** Modify `shell/bar.luau` (and `shell/islands.luau` for the audio watch it already has, if the osd source lives there); Test `tests/unit/run.lua`

**Interfaces:**
- Consumes: `lib/pill`; the watches the bar has (`media`, `battery`, `brightness`; `audio` in islands.luau; notifications through mooi.luau's Signal Loom feed; `fact.recording`).
- Produces: bar facts `pill_on` (bool), `pill_x`, `pill_w`, `pill_kind` (0 idle · 1 music · 2 osd · 3 notify · 4 record · 5 battery), `pill_two`, `pill_val` (0..1), texts `pill_t1`, `pill_t2`; split: `pill_split` (bool), `pill_kind2`, `pill_w1` (left half width), text `pill_s1`; moons: `moon_n`, and for k = 0..3 `moon_x{k}`, `moon_k{k}`. `bar-geo.json` gains `pill = {x, w}` and `moons = { {x, w}… }` (moons 24 px, 8 px apart, left of the Pill then right, alternating).
- Layout in Pill mode: the layout runs as Islands with `center = {}` (and `left = right = {}` when `pill.sides = hide`) — the settings lists themselves are never changed; the Pill sits at `(screen - pill_w) / 2`.
