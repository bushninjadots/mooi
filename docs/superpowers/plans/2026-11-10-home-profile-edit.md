# Home's Profile Moves Down and Becomes Editable — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put Home's profile card under the clock/date/weather/battery header, and let the owner change the display name and picture in place.

**Architecture:** `lib/node/home` gains one pure name validator. `tools/gen-node.py` moves the existing card block and adds an edit overlay (input, picture zone, check). `shell/mooi-node.luau` owns the edit state, writes the name through `lib/settingsfile` (never a command line), and imports pictures with `zenity` → `mooi identity avatar`. Settings are re-read and the card redrawn when either save lands.

**Tech Stack:** Pleamar 0.9 scene DSL generated by `tools/gen-node.py`; Luau logic; Lua 5.4 unit tests.

**Spec:** `docs/superpowers/specs/2026-11-10-home-profile-design.md` (the `## Revision: under the header, and editable` section)

- Commit messages end with `Co-Authored-By: opencode <noreply@opencode.ai>`.

## Review Focus

- An empty or whitespace-only name: the editor must stay open and nothing is written.
- A name with control characters or over 48 characters: control characters are removed, the rest clipped, and a non-empty result saves.
- A missing avatar file, a cancelled zenity dialog, or a failed import: the current picture and name stay, and the node does not die.
- Escape while editing: cancel the edit instead of closing the panel.
- A failed settings write: the editor stays open and the card does not pretend the name changed.

```lua
-- the name the inline editor will keep: trimmed, no control characters, nothing for nothing, 48 at most
function M.name(value)
    value = trim(value):gsub("%c", "")
    value = trim(value)
    if value == "" then return nil end
    return string.sub(value, 1, 48)
end
```

- [ ] **Step 6: Wire the logic**

At the top add `local SETTINGS = require("lib/settingsfile")` and `local SETTINGS_FILE = "settings.json"`.

Add after `N.show_identity`:

```lua
N.hedit, N.hn = false, ""

local function close_editor()
    N.hedit, fact.nd_hedit, N.hn, text.nd_hn = false, false, "", ""
end
N.close_editor = close_editor

local function save_name()
    local name = HM.name(N.hn)
    if not name then return false end
    local before = read(SETTINGS_FILE, "json")
    if type(before) ~= "table" then return false end
    local after = SETTINGS.copy(before)
    after.nexus = type(after.nexus) == "table" and after.nexus or {}
    after.nexus.identity = type(after.nexus.identity) == "table" and after.nexus.identity or {}
    after.nexus.identity.name = name
    local doc = SETTINGS.save(sys, SETTINGS_FILE, before, after, function()
        local s, _, _, state = config.parse(read(SETTINGS_FILE), json.decode)
        if state == "broken" then return nil end
        return s
    end)
    if not doc then return false end
    N.settings = config.parse(read(SETTINGS_FILE), json.decode)
    N.show_identity()
    N.close_editor()
    render()
    return true
end

on("nd_hopen", function()
    N.hedit, fact.nd_hedit = true, true
    N.hn = text.nd_hname or ""
    text.nd_hn = N.hn
    render()
end)
on("text:nd_hn", function(v) N.hn = tostring(v or "") end)
on("nd_hsave", function() save_name() end)
on("nd_hdone", function() save_name() end)
on("nd_hpic", function()
    pcall(run, "zenity", { "--file-selection", "--title=Choose your profile picture",
        "--file-filter=Images | *.png *.jpg *.jpeg *.webp *.avif" }, function(out, code)
        local path = tostring(out or ""):gsub("%s+$", "")
        if code ~= 0 or path == "" then return end
        run("mooi", { "identity", "avatar", path }, function(_, done)
            if done ~= 0 then return end
            N.settings = config.parse(read(SETTINGS_FILE), json.decode)
            N.show_identity()
            render()
        end)
    end)
end)
```
