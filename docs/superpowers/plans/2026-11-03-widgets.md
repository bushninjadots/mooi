# Desktop Widgets (Now Playing + Visualiser) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Pleamar widget program (`mooi-widgets`) with a Now Playing widget (Sleeve, Lyric stage, Record) and a Visualiser widget (12 modes). Widgets are placed in a desktop edit mode or from a Settings page, saved in `widgets.json`, and replace Quickshell `desktop-widgets`.

**Architecture:** One program: `shell/mooi-widgets.plm` + `.luau`.
- **Surface:** one full-screen click-through surface on the `bottom` layer, under the Desk's `fore`.
- **Model:** a pure module `lib/widgets` validates the saved state and works out layout, snapping and idle.
- **Look:** in `ui/widgets.plm`, with the six new visualiser modes added to `ui/viz.plm`.
- **Inputs:** the bar's `viz-levels.txt` (through `lib/vizfeed`) and the MPRIS `media` service.
- **Lifecycle:** the bar spawns and keeps the program like the desk and the frame.

**Tech Stack:** Pleamar 0.7.11 (scenes `language 0.9`), Luau logic in the Lua 5.4 / Luau common subset, unit tests in `tests/unit/run.lua` (lua5.4).

**Spec:** `docs/superpowers/specs/2026-11-03-widgets-design.md`

## Global Constraints

- **Language.** Every new `.plm` starts with `language 0.9`. Every `.luau` must parse under `lua5.4`, because `bin/mooi check` loads each one.
- **Event payloads** are float32. Pack every number sent to the logic under 2^24 (16 777 216).
- **Atomic writes.** `widgets.json` is written atomically: write `widgets.json.tmp` with `files.write`, then `mv` it over the real file. It is written once per finished gesture, never per pointer move.
- **Layout table (px):** min / default / max.
  - `sleeve` 288×104 / 432×152 / 864×304
  - `lyricstage` 480×160 / 960×240 / 1920×480
  - `record` 200×248 / 280×352 / 480×600, fixed aspect
  - `visualiser` 160×64 / 640×160 / screen
- **Grid.** 8 px. Edge and widget snapping happens within 8 px.
- **Scale.** `u = h / default_h` (`w / default_w` for the visualiser).
- **Idle rules:** `hide` | `rest` | `marker`. Defaults: nowplaying `rest`, visualiser `hide`. `rest` dims to 35 % opacity.
- **Modes, in this order** (their index is the mode code): `spectrum mirror ring aurora led orbit scope horizon dust ripple skyline liquid`.
- **Widget cap: at most 8 widgets** (the scene's model has `max 8`). Extra entries are dropped with a log line. *Plan decision; the spec says "a list".*
- **Defaults** when the file is missing: one `sleeve` at x=64, y=1080−152−64 (bottom left, 64 px margins), idle `rest`. No visualiser.
- **Rate:** `rate: 60, 4 while calm`.
- **GPU budget**, measured with DRM fdinfo `drm-engine-gfx` per pid: idle < 1 %; Sleeve + full-width visualiser playing < 8 %.
- **No visualiser on any border** (the frame stays as it is).
- **Before every commit:** run `bash setup/capture.sh`. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and are pushed to `origin main`.

## Review Focus

1. **A widget dragged half off screen, or a saved file from a bigger monitor.** It should land fully on screen, below the bar's reserve. → test `clamp_rect keeps a widget on screen and under the bar` (Task 1).
2. **Track change mid-lyric, or a track with no artist (a browser tab).** The lines must clear at once. There must be no LRCLIB call with an empty artist. → test `lyric_lines on nil data gives empty lines` (Task 2) + live check (Task 4).
3. **Two widgets dropped on the same spot via `+ Add`.** The new one should go to free space, not on top. → test `free_spot avoids existing widgets` (Task 1).
4. **The settings window and edit mode both write `widgets.json`.** The last write wins, and both stay consistent. The program reloads on the file watch, but must not reload its own write mid-drag. → test `same_doc ignores own write` (Task 1) + live check (Task 7).
5. **Media stops, then the player closes (MPRIS disappears).** Widgets move to their idle rule, not frozen on the last frame. The visualiser rests when the feed goes stale (> 1 s). → live check in Task 5.

### Task 1: The model, `lib/widgets`

**Files:**
- Create: `shell/lib/widgets.luau`
- Test: `tests/unit/run.lua` (new `print("widgets")` section before the final summary line)

**Interfaces:**
- Produces (module table `W`):
  - Constants and tables:
    - `W.GRID = 8`, `W.MAX = 8`, `W.FILE = "widgets.json"`
    - `W.LAYOUTS[name] = { min = {w,h}, def = {w,h}, max = {w,h} | nil, aspect = bool }` for `sleeve`, `lyricstage`, `record`, `visualiser`
    - `W.MODES` (array of 12 names), `W.MODE_INDEX[name] -> 0..11`
    - `W.IDLE_INDEX = { hide = 0, rest = 1, marker = 2 }`
  - Reading and writing the document:
    - `W.defaults(screen_w, screen_h) -> doc`
    - `W.parse(raw_text_or_nil, decode, screen) -> doc, problems` (`problems` is an array of strings; `doc.bad == true` when the file did not decode)
    - `W.encode(doc) -> table` (what gets written)
  - Geometry:
    - `W.layout_of(widget) -> name` (`"visualiser"` for that kind)
    - `W.clamp_size(widget, w, h) -> w, h` (min/max, aspect for record, 8 px)
    - `W.clamp_rect(widget, screen) -> widget` (fully on screen, `y >= screen.top`, the bar's reserve)
    - `W.scale(widget) -> u`
    - `W.snap(doc, index, x, y, w, h, screen) -> x, y, w, h, guides` (`guides = { vx = px|nil, hy = px|nil }`)
    - `W.free_spot(doc, layout, screen) -> x, y`
  - Editing:
    - `W.add(doc, kind, screen) -> doc, id`
    - `W.remove(doc, id) -> doc`
    - `W.duplicate(doc, id, screen) -> doc, id`
    - `W.set_layout(doc, id, layout, screen) -> doc` (keeps x/y, size becomes the new default clamped, kept on screen)
  - Idle and saving:
    - `W.idle_state(widget, playing) -> "shown" | "rest" | "hidden" | "marker"`
    - `W.same_doc(a, b) -> bool` (deep equality of encoded docs)
  - Event packing:
    - `W.pack(slot, gx, gy) -> n = slot*65536 + gx*256 + gy`
    - `W.unpack(n) -> slot, gx, gy` (slot 0..7, gx and gy in grid units 0..255)
  - `screen` is always `{ w, h, top }`, where `top` is the bar's reserve in px.
- Consumes: nothing (pure; `decode` is injected like `lib/config.parse`).

### Task 3: Six new visualiser modes in `ui/viz.plm`

**Files:**
- Modify: `shell/ui/viz.plm`
- Create (scratch only, not committed): a lab scene in the session scratchpad that imports `ui/viz.plm` and shows all 12 modes in a 4×3 grid on fake bands (`wave`-driven facts).

**Interfaces:**
- Produces library components, each `(x, y, w, h, t1: color, t2: color, still: bool = false, …)`, reading the scene's `vb0…vb15` like the existing six:
  - `Scope(…, trail1: number, trail2: number)`: the main trace plus two afterimage traces at 45 % / 20 % alpha, offset in phase by `trail1` / `trail2` (the scene feeds them from lagged springs).
  - `Horizon(…, turn: number)`: four filled layers, made of straight steps (≤ 48 per layer).
  - `Dust(…, scatter: number, turn: number)`: 96 specks at hash-fixed base positions. They drift by `turn`, are pushed outward by `scatter` (0..1), and are drawn as one `repeat`.
  - `Ripple(…, r0, a0, r1, a1, r2, a2, r3, a3: number)`: four rings, radius as a share of `min(w, h) / 2`, alpha 0..1.
  - `Skyline(…)`: 16 bars on a line at 62 % height, with a 22 %-alpha reflection at 55 % length.
  - `Liquid(…, turn: number)`: a 48-step closed path, radius `R·(1 + band·0.45)`, bass at the bottom and treble at the top.
- **Library components hold no state.** Every memory (trail lag, scatter, ring pool) lives in the scene that uses them and comes in as parameters.

### Task 5: Calm until touched, idle rules, cost

**Files:**
- Modify: `shell/mooi-widgets.plm`, `shell/mooi-widgets.luau`, `shell/ui/widgets.plm`

**Interfaces:**
- Consumes: `W.idle_state` (Task 1); the `media` service calls `media.toggle`, `media.next`, `media.previous`; `playerctl position <s>` for seeking; `audio.volume`.
- Scene events sent to the logic:
  - `wg_ctl(n)`: n = slot·10 + {0 prev, 1 toggle, 2 next}
  - `wg_seek(n)`: n = slot·1000 + permille
  - `wg_vol(n)`: n = slot·10 + {0 down, 1 up}
  - `wg_open(slot)`
- Calm fact: `calm = not np_playing and not editing and hover_any == 0`.

- [ ] **Step 1: Add the zones.** Each Now Playing widget gets zones only on its cover/record, its control row and its progress trace. Everything else on the surface passes through.
  - On hover: lift 2·u px and brighten the rim. Controls fade in and fade out 1.2 s after the pointer leaves.
  - Scrolling on the widget sends `wg_vol` when the widget's `scroll_volume` option is set.
  - A press on the cover sends `wg_open`, and the logic runs `launch("mooi", { "player" })`.
  - The visualiser has no zones.

- [ ] **Step 2: Apply the idle rules** from `W.idle_state`:
  - `rest`: 35 %, last track kept, record stopped, tonearm at `ARM_REST`
