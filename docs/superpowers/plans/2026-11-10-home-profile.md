# Home Profile Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open the Pill's Home page with a profile card above the clock: the owner's picture, display name and hostname.

**Architecture:** A pure `HM.identity` helper derives the three words and the fallback initial; `tools/gen-node.py` draws a 58 px inset card and shifts every Home row down by 58 px; `shell/mooi-node.luau` reads the Nexus identity and the hostname and updates the scene when `settings.json` changes.

**Tech Stack:** Luau logic, Pleamar scene DSL generated by Python, Lua 5.4 unit tests.

**Spec:** `docs/superpowers/specs/2026-11-10-home-profile-design.md`

## Global Constraints

- Never hand-edit `shell/mooi-node.plm`; edit `tools/gen-node.py` and run `python3 tools/gen-node.py`.
- Luau: no bitwise operators (`& | ~ << >>`), no `goto`, no empty-matching `gmatch`; `//` is allowed; every `local` is declared before its first use.
- Every calendar page (500 px wide) keeps its width; only Home's height changes, 660 → 718.
- Colours come only from `fl.*` and the accent; Nerd Font glyphs use `family: "CaskaydiaCove Nerd Font"`.
- No typed or copied content on a command line; this change writes no files.
- Tests: pure helpers in `tests/unit/node_helpers.lua` (receives `section, test, eq`), scene-string checks with `io.open`.

## Review Focus

- An empty or missing display name must show `mooi` and the initial `M`, never an empty card.
- Whitespace around the name or hostname must be trimmed before drawing.
- No avatar must hide the image and show the initial; a set avatar must hide the initial and show the picture.
- `hostname` failing or printing nothing must leave a working card, not an error or a stale name.
- A change to `settings.json` must refresh the card without closing and reopening the panel.

- [ ] **Step 3: Implement it in `shell/lib/node/home.luau`**

Add a local `trim` and `M.identity` before `return M`:

```lua
local function trim(s)
    s = type(s) == "string" and s or ""
    s = s:gsub("^%s+", "")
    s = s:gsub("%s+$", "")
    return s
end

-- the profile card's words: the display name (never empty), the hostname, the picture's file, and the letter
-- shown when there is no picture
function M.identity(name, host, avatar)
    name = trim(name)
    if name == "" then name = "mooi" end
    host = trim(host)
    avatar = trim(avatar)
    return { name = name, host = host, avatar = avatar, initial = string.upper(string.sub(name, 1, 1)) }
end
```

- [ ] **Step 6: Add the logic**

In `shell/mooi-node.luau`, before `show_panel_home`, add:

```lua
local HOME_FOLDER = tostring(sys.ask("files.folder") or "")

N.host = ""
N.show_identity = function()
    local nx = type(N.settings.nexus) == "table" and N.settings.nexus or {}
    local id = type(nx.identity) == "table" and nx.identity or {}
    local who = HM.identity(id.name, N.host, id.avatar)
    text.nd_hname, text.nd_hwho, text.nd_hinit = who.name, who.host, who.initial
    text.nd_face = who.avatar ~= "" and (HOME_FOLDER .. "/" .. who.avatar) or ""
    fact.nd_face_on = text.nd_face ~= ""
end
N.show_identity()
run("hostname", {}, function(out)
    N.host = (tostring(out or ""):gsub("^%s+", ""):gsub("%s+$", ""))
    N.show_identity()
    render()
end)
```
