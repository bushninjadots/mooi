# BMO Bar Module and Herdr Island Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give BMO a normal, placeable bar module with a live face, landing island, shared pet state, chat and permissioned actions; then add a Herdr module and island that briefs coding agents.

**Architecture:** The bar is the single owner of BMO's shared state (`bmo-shared.json`) and chat; the desktop body, Pill and Sigil read it and send intents. Pure Lua modules (`bmostate`, `bmochat`, `bmoact`, `herdrfeed`) hold all logic; `bar.luau` runs processes and facts, `mooi.plm` only draws. Both modules are appended after `sigil`, start on the shelf, and are placed through edit mode.

**Tech Stack:** Luau logic, Pleamar 0.9 scenes, Lua 5.4 unit tests, JSON state files, Herdr CLI.

**Spec:** `docs/superpowers/specs/2026-11-08-bmo-herdr-design.md`

## Global Constraints

- Add modules only after `sigil`: `bmo` gets edit code 33, `herdr` code 34.
- Neither module enters `barlayout.DEFAULT`; the 1920 px fit test must stay green.
- Every new setting is appended to `lib/setters.luau`; generated settings scenes are never hand-edited.
- The bar writes `bmo-shared.json`, `bmo-chat.json`, `bmo-actions.json`, `herdr-seen.json`; the desktop writes only `bmo-body.json` and `bmo-cmd.json`.
- Files outside Pleamar's sandbox are changed only through `run` (`cp`, `mv`, `rm`) with a backup, under `$HOME`, never sudo, never credentials.
- Cheek levels are Off / Tease / Flirty / Unfiltered; explicit content, slurs and non-consensual content are out at every level.
- Every phase must pass `bin/mooi check`.

## Review Focus

- A missing or corrupt state file must leave the bar alive with a default BMO, never a crash.
- A click shorter than 450 ms opens the island; a longer hold charges and never opens it on release.
- The desktop body being closed must not change BMO's mood or stop the bar face.
- Herdr returning no server, bad JSON, or no agents must hide gracefully, not error.
- File edits must refuse traversal, symlink escapes, secrets and `sudo`, and keep a backup.
