# mooi · The complete design philosophy

> The user's own statement of direction (2026-10-19), kept as written (reference images left out).
> Read with [VISION.md](VISION.md). Every new feature is checked against these six directions.

The entire mooi environment must be built around six inseparable design directions. These aren't just visual styles we apply afterward. They must influence how every component looks, moves, responds, connects and behaves, from the system settings and file manager to terminal themes, widgets, layouts and customization tools.

## 1. Spatial & Futuristic

Depth · Spatial relationships · Dimensional interfaces

The desktop should feel like an environment with space and structure, not a flat collection of windows. Interfaces can expand into spatial overviews, contextual layers and dimensional arrangements. Depth should communicate hierarchy and relationships, never become meaningless decoration.

## 2. Industrial & Technical

Precision · Mechanical geometry · Engineered structure

Components should feel deliberately constructed. Angular forms, chamfered edges, technical typography, structured surfaces and precise alignment establish mooi's industrial identity. Settings, controls and layouts should feel like parts of a coherent machine, not generic rounded cards.

## 3. Organic & Fluid

Continuity · Responsive motion · Natural transitions

The environment should flow between states. Panels transform, layouts rearrange and interactions respond naturally to input. Movement should feel continuous, weighted and intentional, with shared animation principles throughout the system. Fluidity must never come at the expense of speed or clarity.

## 4. Minimal & Elegant

Clarity · Restraint · Purposeful detail

The everyday desktop remains clean and focused. Every visible element must earn its place. We avoid oversized cards, excessive rounding, unnecessary gradients and permanently visible clutter. Complexity should emerge through interaction and customization, not overwhelm the user at rest.

## 5. Cyberpunk & Expressive

Character · Contrast · Controlled visual energy

mooi needs a recognizable personality. Accent colors, luminous indicators, technical markings, layered effects and expressive states give it character. This direction provides energy without turning every surface into a neon spectacle. Users should be able to control how subtle or expressive their environment becomes.

## 6. Playful & Interactive

Discovery · Tactility · Creative control

The desktop should be enjoyable to explore. Components can react to pointer movement, respond to gestures, morph into new forms and reveal contextual actions. Users should be encouraged to experiment with layouts, widgets, themes and interactions, with previews, undo and safe defaults.

## How the six directions work together

They must operate as a single design system, not six independent themes.

| Direction              | What it contributes to mooi                      |
| ---------------------- | ------------------------------------------------ |
| Spatial & Futuristic   | How the environment is structured and perceived  |
| Industrial & Technical | How components are shaped and organized          |
| Organic & Fluid        | How the environment moves and transitions        |
| Minimal & Elegant      | How information stays clear and focused          |
| Cyberpunk & Expressive | How the system develops character and atmosphere |
| Playful & Interactive  | How people explore, manipulate and customize it  |

These six directions must inform every part of the project:

- Color engine: adaptive palettes, theme ingredients and system-wide color coordination.
- Applications: file manager, terminal, settings, dialogs, menus and application integrations.
- Desktop: widgets, window layouts, workspace environments and spatial overviews.
- Motion: transitions, spring behavior, gestures, shaders and interactive effects.
- System controls: displays, audio, networking, power, accessibility, privacy and available hardware settings.
- Customization: visual editor, reusable components, theme presets, advanced configuration and layout authoring.

The final result should not look like a generic Linux desktop with a futuristic skin. It should feel like a cohesive, spatial, mechanically inspired and fluid computing environment that users can reshape to their own needs.

These six directions are the permanent creative foundation of mooi. Every new feature should be designed with all six in mind, balanced according to the feature's purpose rather than forcing every direction to be equally visible everywhere.
